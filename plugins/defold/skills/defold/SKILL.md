# Defold

Work on Defold projects with the `defold` MCP tools:

- `status` first, to see the Defold version, the project and whether the editor is open.
- `api` to check exact Lua signatures for the installed version instead of relying on memory.
- `build` after edits, `run` + `logs` + `screenshot` to see the result.
